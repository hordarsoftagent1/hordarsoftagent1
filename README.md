## What I work on

Production Ruby on Rails 8 backends on PostgreSQL — ERP and logistics systems
(CEDIS/POS), multi-tenant SaaS, payments with Stripe, and the infrastructure
around them.

- **Rails 8** with the **Solid Trifecta** (`solid_queue`, `solid_cache`,
  `solid_cable`) instead of the usual Redis/Sidekiq pair
- **Multi-tenancy** with `acts_as_tenant`, authorization with Pundit
- **React + Inertia.js** frontends over a Rails API, Hotwire where it fits
- **Concurrency done carefully** — `with_lock` on critical paths, idempotency
  keys on writes, append-only audit trails
- **Docker + Dokploy** for deployment, GitHub Actions for CI
